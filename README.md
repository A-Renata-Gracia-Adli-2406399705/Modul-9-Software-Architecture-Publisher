# Preparing the publisher

a. Dalam satu kali program publisher dijalankan, program akan mengirimkan 5 event ke message broker RabbitMQ. Setiap event berisi data user_id dan user_name yang merepresentasikan informasi pengguna. Kelima event tersebut dikirim secara berurutan menggunakan fungsi publish_event. Message yang dikirim akan masuk ke queue bernama "user_created" sebelum diproses oleh subscriber. Jumlah data yang dikirim memang tidak terlalu besar, tetapi tutorial ini menunjukkan bagaimana publisher dapat terus mengirim event tanpa harus menunggu subscriber selesai memproses data sebelumnya. Konsep ini sangat berguna pada sistem dengan traffic tinggi karena proses pengiriman dan pemrosesan data dapat dipisahkan secara asynchronous.

b. URL "amqp://guest:guest@localhost:5672" digunakan untuk menghubungkan publisher ke RabbitMQ sebagai message broker. Bagian "amqp" menunjukkan bahwa protokol yang digunakan adalah AMQP atau Advanced Message Queuing Protocol. Username dan password yang digunakan pada tutorial ini adalah "guest" dan "guest", yang merupakan default credential dari RabbitMQ. Host "localhost" berarti RabbitMQ berjalan di komputer lokal yang sama dengan aplikasi publisher dan subscriber. Sementara itu, port 5672 merupakan port standar yang digunakan RabbitMQ untuk komunikasi AMQP. Karena publisher dan subscriber menggunakan URL yang sama, keduanya dapat terhubung ke broker yang sama dan saling bertukar event melalui queue yang tersedia.
